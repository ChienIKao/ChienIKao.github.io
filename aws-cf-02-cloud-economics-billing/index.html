Cloud Economics and Billing — 定價基礎、總擁有成本、AWS Organizations、帳單工具、技術支援方案。針對 AWS Certified Cloud Practitioner 考試整理重點與常見誤區。

# 2.1 定價基礎知識

定義

AWS 的費用來自三大成本驅動因素: 運算 (Compute)、儲存 (Storage)、對外資料傳輸 (Outbound Data Transfer)。這三個是必考題。

考試重點

關於資料傳輸有個常考的關鍵細節: 資料「傳入」AWS 通常免費，「傳出」到網際網路才收費，而且同一區域內多數服務之間的傳輸也免費。看到題目問「哪種資料傳輸不收費」, 答案通常是「傳入 (inbound)」。

# 四個定價原則

  • 按使用量付費 (Pay as you go): 不必長期合約，用多少付多少
  • 預留可省更多 (Save when you reserve): 承諾長期使用可換取大幅折扣
  • 用得越多單價越低 (Pay less by using more): 如 S3 有階梯式定價
  • AWS 成長，你付更少：AWS 規模擴大後持續調降價格

# AWS 免費方案 (Free Tier)

新帳戶可享用免費額度，分三種類型:12 個月免費 (如 EC2 t2.micro 每月 750 小時)、永久免費 (如 Lambda 每月 100 萬次請求)、短期試用 (特定服務的限時體驗)。

# 2.2 總擁有成本 (TCO)

生活比喻

買車的成本不只是車價，還有保險、油錢、保養、停車位。自建機房也一樣 —— 伺服器只是其中一筆，還有機房租金、電費、冷卻、網路、維運人力、硬體汰換。TCO 就是把這些隱藏成本全部算進去，才能公平比較自建與上雲。

定義

資本支出 (CapEx): 一次性的大額前期投資，例如買伺服器 —— 這是傳統機房的模式。營運支出 (OpEx): 持續性的按用量支出，例如每月的雲端帳單 —— 這是雲端的模式。上雲的核心財務效益就是把 CapEx 轉為 OpEx。

自建機房會產生但上雲後可省下的成本包括：實體伺服器與機架、機房空間與租金、電力與冷卻、網路設備、硬體維護與汰換、以及維運人力。

估算工具:AWS Pricing Calculator (AWS 定價計算器) 可以在建置前先估算方案費用，是課程與考試都會提到的官方工具。

# 2.3 AWS Organizations

生活比喻

一個家庭裡每個人都有手機門號，但爸爸辦了「家族方案」—— 所有門號的帳單合併成一張、總用量越多折扣越好，而且爸爸還能設定「小孩的門號不能打國際電話」。AWS Organizations 就是這個家族方案。

功能說明
合併帳單 (Consolidated Billing)多個帳戶的費用集中成一張帳單，由管理帳戶付款
批量折扣所有帳戶的用量合併計算，更容易達到階梯折扣門檻
組織單位 (OU)把帳戶分組管理，方便按部門或環境套用不同政策
服務控制政策 (SCP)設定帳戶「最多能做什麼」的權限上限，即使是該帳戶的管理員也不能超出

考試重點

兩個高頻考點：第一， 合併帳單能讓用量加總以取得更好的折扣 —— 這是 Organizations 最常考的好處。第二，SCP 設定的是「權限上限」, 不是「授予權限」—— 它只能限制，不能給權，實際權限仍要靠 IAM 授予。

# 2.4 帳單與成本管理工具

工具用途白話理解
Billing Dashboard總覽目前的費用與趨勢帳單首頁，快速看這個月花多少
AWS Cost Explorer視覺化分析歷史費用，可依服務、帳戶、標籤切分，並預測未來成本花費的分析報表工具
AWS Budgets設定預算門檻， 接近或超出時發送警示預算警報器
Cost and Usage Report最詳細的逐項用量與費用報告，可匯出分析完整的原始帳目明細
Cost Allocation Tags用標籤標記資源，讓費用能歸屬到專案或部門幫每筆花費貼上部門標籤

常見誤區

Cost Explorer 是「分析已經花的錢」,Budgets 是「預先設門檻並在超支前警告」。題目若說「想在費用超過某金額時收到通知」→ 答案是 AWS Budgets, 不是 Cost Explorer。這組區辨很常考。

# 2.5 技術支援方案

方案包含什麼Trusted Advisor 檢查
Basic (基本)免費；客戶服務、文件、論壇、Personal Health Dashboard僅部分核心檢查
Developer (開發人員)營業時間內的技術支援 (email), 適合測試與開發環境僅部分核心檢查
Business (商業)24×7 全天候電話、email、聊天支援；適合正式環境完整全部檢查
Enterprise (企業)最高等級；提供專屬技術客戶經理 (TAM)、最快回應時間完整全部檢查

考試重點

三個記憶錨點:Basic 免費、Business 起才有 24×7 支援與完整的 Trusted Advisor 檢查、Enterprise 才有專屬技術客戶經理 (TAM)。題目若說「需要專屬的技術客戶經理」→ 答案一定是 Enterprise。(AWS 後來另有 Enterprise On-Ramp 方案介於 Business 與 Enterprise 之間，課程作業以四種方案為準。)

# 2.6 詞彙速查

名稱一句話定義
CapEx / OpEx資本支出 (前期大額)/ 營運支出 (按用量持續)
TCO總擁有成本，含所有隱藏的機房與維運成本
Pricing Calculator建置前估算 AWS 費用的官方工具
Organizations集中管理多個帳戶，合併帳單與套用政策
SCP服務控制政策，設定帳戶的權限上限
Cost Explorer分析歷史費用並預測趨勢
AWS Budgets設定預算門檻並在接近或超出時警示
TAM技術客戶經理，僅 Enterprise 支援方案提供

# 重點回顧

  • 三大成本驅動因素：運算、儲存、對外資料傳輸；資料傳入免費，傳出才收費。
  • 上雲的核心財務效益是把 CapEx (前期資本支出) 轉為 OpEx (按用量營運支出)。
  • Organizations 提供合併帳單，用量加總後更容易取得批量折扣；SCP 只能設上限，不能授權。
  • Cost Explorer 分析已發生的費用，Budgets 預先設門檻並警示。
  • 支援方案：Basic 免費；Business 起有 24×7 支援與完整 Trusted Advisor;Enterprise 才有 TAM。

# 自我測驗

AWS 的三大成本驅動因素是什麼?

答：運算 (Compute)、儲存 (Storage)、對外資料傳輸 (Outbound Data Transfer)。

想在每月費用超過 500 美元時收到通知,該用哪個工具?

答：AWS Budgets。 Cost Explorer 是分析已發生的費用，Budgets 才能設定門檻並主動警示。

使用 AWS Organizations 的合併帳單有什麼主要好處?

答：所有帳戶的用量合併計算，更容易達到批量折扣門檻，並且只需管理一張帳單。

哪個支援方案才提供專屬的技術客戶經理(TAM)?

答：Enterprise (企業) 支援方案。 Business 方案有 24×7 支援與完整 Trusted Advisor 檢查，但沒有專屬 TAM。

資料傳入 AWS 和傳出 AWS,哪一個要收費?

答：傳出 (outbound) 到網際網路才收費，傳入 (inbound) 通常免費。
